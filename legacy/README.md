# legacy

`v1-assets/` is the art and audio from Namma Quest v1.0 (the `v1.0` branch), moved here
from `public/assets/` so it is kept but not shipped: anything under `public/` is copied into
every build and precached by the PWA service worker, and the current game does not use it.

The v1 tools in `tools/` and the v1 notes at the repo root (`SPRITE_*`, `TILESET_*`,
`MIGRATION_COMPLETE.md`, …) still refer to `public/assets/`; read that as `legacy/v1-assets/`.
The current game's art lives in `src/assets/` and is generated by `npm run art`.
